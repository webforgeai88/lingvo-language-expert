# Lingvo — сайт эксперта иностранных языков

Учебный проект: адаптивный лендинг для занятий английским, немецким, французским, корейским и китайским языками.

## Возможности

- Семь основных блоков: главный экран, языки, преподаватель, методика, услуги и цены, отзывы, финальный призыв.
- Выбор языка с обновлением карточки и автоматическим заполнением формы.
- Выбор программы обучения, проверка формы и маска телефона.
- Мобильное меню и переключение отзывов.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей не требуется.

## Состав

- `index.html` — страница, стили и интерактивность.
- `hero.jpg`, `cheer.jpg`, `teacher.jpg` — изображения сайта.

Это демонстрационный учебный проект. Данные преподавателя, достижения, цены и отзывы — примеры. Заявки сохраняются только в localStorage браузера; отправка преподавателю не подключена.
